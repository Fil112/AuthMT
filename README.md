# AuthMT

**AuthMT** — это легковесный и производительный плагин для авторизации на Minecraft серверах. Разработан специально для серверов с ограниченными ресурсами, обеспечивая стабильную работу без просадок TPS.

## 🚀 Основные возможности
* **Асинхронная обработка:** Все запросы к базе данных выполняются в отдельных потоках, что исключает фризы сервера.
* **Гибкое хранилище:** Поддержка **SQLite** (локальный файл), **MySQL** (для удаленных баз) и **File** (простой YML).
* **Безопасность:** Пароли защищены хэшированием **SHA-256**.
* **Защита игрока:** Блокировка движения, чата и команд до момента успешной авторизации.
* **Гибкая конфигурация:** Возможность настройки сообщений и времени сессии под свои нужды.

## 🛠 Установка
1. Поместите `AuthMT.jar` в папку `/plugins/` вашего сервера.
2. Запустите сервер для генерации конфигурационных файлов.
3. Отредактируйте `config.yml` в папке `/plugins/AuthMT/` (выберите тип базы данных: `sqlite`, `mysql` или `file`).

## 📝 Команды
* `/register <пароль> <повтор_пароля>` — Регистрация нового аккаунта.
* `/login <пароль>` — Вход в существующий аккаунт.

## ⚙️ Настройки (config.yml)
В файле `config.yml` вы можете настроить:
- **storage-type**: Выбор базы данных (`sqlite`, `mysql`, `file`).
- **auth-world**: Название мира, куда телепортируются неавторизованные игроки.
- **session-timeout-minutes**: Время (в минутах), в течение которого игрок считается авторизованным после выхода.

## 💻 Технический стек
* **Java 1.8+**
* **Spigot API 1.16+**
